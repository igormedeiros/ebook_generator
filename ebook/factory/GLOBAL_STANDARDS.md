# Padrões Globais da Fábrica (GLOBAL_STANDARDS.md)

Este documento define as regras imutáveis de qualidade, didática e engenharia de conteúdo para todos os e-books gerados por esta plataforma.

## 1. Padrões de Qualidade Técnica
- **Idioma:** Português do Brasil (pt-BR).
- **Formatação:** Markdown Extended/GFM (compatível com Pandoc).
- **Metadados Obrigatórios:** Título, Subtítulo, Autor, Blurb, Categorias BISAC.
- **Saída:** Arquivo EPUB otimizado para Amazon Kindle.

## 2. Engenharia de Conteúdo (Métricas)
- **Extensão Alvo:** 15.000 a 20.000 palavras.
- **Estrutura:** 10 capítulos obrigatórios + Introdução + Conclusão.
- **Proporção Didática:** 70% Prática (Hands-on) / 30% Teoria (Conceitos/Ética).

## 3. Estilo e Tom (A Tríade Editorial)
- **POV Principal:** Segunda pessoa ("Você") para engajar o leitor.
- **Momento Hands-on:** Inclusivo ("Nós") durante códigos e exercícios.
- **Storytelling:** Uso estratégico da primeira pessoa ("Eu") para inserir as vivências do `STORIES.md`.
- **Atmosfera:** Técnico, amigável, acolhedor e profundamente didático.

## 4. Apresentação Técnica (A Tríade de Código)
1. **Contexto:** Desenho do problema técnico/clínico.
2. **Código:** Bloco limpo, com Type Hints e comentários em inglês.
3. **Dissecação:** Explicação linha a linha focada em "cicatrizes de produção".

## 5. Estrutura Padrão do Livro
- Capa (Assets)
- Página de Título e Copyright
- Dedicatória
- Sumário (Dinâmico)
- Prefácio/Introdução
- 10 Capítulos Técnicos
- Conclusão/Próximos Passos
- Sobre o Autor
- Glossário
