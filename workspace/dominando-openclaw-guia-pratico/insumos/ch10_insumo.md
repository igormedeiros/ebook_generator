## Cicatrizes de Produção
- A dependência excessiva de uma única API (ex: apenas Anthropic) é um risco de soberania; a estratégia híbrida com Ollama é a única defesa real contra mudanças de preço ou censura.
- **Dica:** Tenha sempre um "Plano B" de modelo local (como o Llama 3.3 ou Qwen 3.5) configurado e pronto para assumir.
