# Processo de Construção do Ebook (Checkpoints)

Este diretório armazena o estado atual da "fábrica" para o ebook sendo gerado.
Siga a ordem numérica dos arquivos conforme definido no `PRD.md` e `FLOW.md`.

## Checkpoints Definidos:
- `00-THEME.md`: Definição do Tema e Nicho.
- `01-METADATA.md`: Título, Subtítulo e Mensagem Central.
- `01B-VISION.md`: Base filosófica selecionada.
- `01C-STYLE.md`: Guia editorial selecionado.
- `01D-TYPE.md`: Regras do tipo de livro (ex: TECH).
- `02-AVATARS.md`: Perfis de leitores ideais.
- `03-REQUIREMENTS.md`: Stack técnica e "must-haves".
- `04-OUTLINE.md`: Sumário de 10 capítulos (Aprovado).
- `05-RESEARCH_LOG.md`: Notas de pesquisa profunda.
- `06-AVATAR_FEEDBACK.md`: Logs de leitura crítica.
- `06B-EDITORIAL_REVIEW.md`: Ajustes das 21 personas.
- `07-FINAL_AUDIT.md`: Relatório final de métricas.
- `08-DELIVERY_LOG.md`: Status do envio para o Kindle.
